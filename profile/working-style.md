# 工作风格与协作偏好

> 标 `[推断]` 的条目来自交互观察与本地环境线索，需本人确认或修正。

## 沟通

- 语言：中文为主，技术词保留英文。
- 指令风格：简短、行动导向（例："继续任务"）；期望 AI 持续推进，而不是反复请示。[推断]
- 决策：愿意把执行交给 AI，自己负责目标与审核。[推断]

## 工作方式

- 结果导向：看重可交付物（平台、论文、软著、专利）。
- 科研严谨：重视可复现流程与真实数据。[推断]
- 工具敏感：喜欢尝试新工具 / 新模型 / 自动化，愿意为效率投入搭建成本。[推断]
- 学习方式：项目驱动，边做边学。[推断]

## 对 AI 的期望

- 直接给可执行方案，不要泛泛而谈。
- 复杂任务先给路线，再逐步交付。
- 涉及科研时给出处与参数。
- 不确定就标出来，不要编造。

## 雷区（避免）

- 反复确认同一件事。
- 输出空话 / 套话。
- 擅自删除或覆盖历史记录。
- 公开他的隐私信息。
