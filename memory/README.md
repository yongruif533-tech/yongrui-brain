# 记忆层使用说明

记忆层是这颗大脑"活"的部分：事实层（`profile/`）记录稳定信息，记忆层记录随时间变化的信息。

## 目录

- `journal/YYYY-MM.md`：按月的流水日志（做了什么、产出、下一步）。
- `projects/<slug>.md`：进行中项目的状态快照（每个项目一个文件）。
- `decisions/YYYY-MM-DD-<topic>.md`：重要决策记录（背景、选项、决定、理由）。

## 写入格式（AI 必须遵守）

### 日志条目

```markdown
## YYYY-MM-DD · <标题>

- 做了什么：
- 产出：
- 下一步：
- 涉及文件 / 链接：
```

### 项目快照

```markdown
# 项目名

- 状态：进行中 / 暂停 / 已交付
- 最近更新：YYYY-MM-DD
- 目标：
- 当前进展：
- 阻塞项：
- 下一步：
```

### 决策记录

```markdown
# YYYY-MM-DD · <决策主题>

- 背景：
- 选项：
- 决定：
- 理由：
- 影响 / 后果：
- 何时重新评估：
```

## 规则

1. **只追加，不删除**历史条目（纠错用新条目说明）。
2. 每条记忆注明日期与来源（用户说法 / AI 推断 / 文件证据）。
3. 不确定内容标 `[待确认]`；推断标 `[推断]`。
4. 新的事实若稳定且重要，同步更新到 `profile/` 对应文件。
5. 涉及隐私的内容不要写入本仓库（放本地 `private/`）。
6. 提交信息格式：`memory: <一句话>`。
