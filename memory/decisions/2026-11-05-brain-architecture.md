# 2026-11-05 · 用 Git 仓库作为 AI 共享大脑

- **背景**：日常同时使用多个 AI（ZCode、Cursor、Trae、网页版模型等）、多台电脑；每个平台各自记忆，上下文割裂，换工具即失忆。
- **选项**：
  1. 依赖各平台自带的记忆功能 —— 更新、上限、厂商锁定均不可控；
  2. 本地笔记 / Notion —— 部分 AI 无法直接读取，检索靠人工；
  3. Git 仓库作为唯一事实源，各 AI 通过入口文件读取 —— 可版本化、可迁移、可审计。
- **决定**：采用方案 3。仓库分三层：事实层（`profile/`）、记忆层（`memory/`）、接口层（`AGENTS.md`、`CLAUDE.md`、`prompts/`、`.cursor/`）。
- **理由**：Git 天然支持跨设备同步与历史回溯；Markdown 对任何模型可读；入口文件是当下 AI 工具的通用约定（`AGENTS.md` 已被多个工具采用）。
- **影响 / 后果**：需要养成"工作结束写回 + 提交"的习惯；公开仓库须保持脱敏。
- **何时重新评估**：出现成熟的跨厂商个人上下文协议（如通用 MCP 记忆服务）时，可在此基础上叠加，而非推翻。
